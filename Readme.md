# Stock Portfolio Performance Tracker

## Overview
A Python project that analyzes S&P 500 company data and calculates stock portfolio performance.

## Features
- Loads company data from a CSV file
- Displays company information
- Analyzes companies by sector
- Validates stock tickers
- Calculates investment and current value
- Calculates profit/loss and profit/loss percentage
- Exports reports to CSV files

## Technologies Used
- Python
- Pandas
- CSV

## How to Run
1. Install Pandas using `python -m pip install pandas`
2. Keep `constituents.csv` in the same folder as `stock_tracker.py`
3. Run `python stock_tracker.py`
4. Enter the stock ticker, quantity, buy price and current price
5. Enter `DONE` to finish

## Note
Stock prices are entered manually; the supplied dataset does not contain live market prices.
